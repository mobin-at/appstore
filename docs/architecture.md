# قرارداد ساختار رابط

## جهت محصول

استور اپلیکیشن اندروید برای کاربران ایرانی؛ طراحی‌های بعدی با `lang="fa"`، `dir="rtl"`، متن فارسی و چیدمان مناسب لمس ساخته می‌شوند. صفحهٔ اصلی فعلی فارسی و راست‌به‌چپ است؛ نام اصلی انگلیسی بازی‌ها به صورت مستقل و چپ‌به‌راست نمایش داده می‌شود.

## قرارداد فایل‌ها

- هر صفحه یک پوشهٔ مستقل در `pages/<page-name>/` و فایل `index.html` دارد.
- استایل مشترک در `assets/css/mobile.css` قرار می‌گیرد. هنگام اضافه‌شدن صفحه‌های بیشتر، متغیرها، اجزای مشترک و استایل اختصاصی صفحات به فایل‌های جدا تقسیم می‌شوند.
- اسکریپت مشترک در `assets/js/main.js` است؛ اسکریپت اختصاصی هر صفحه با نام همان صفحه جدا می‌شود.
- تصاویر با مسیر نسبی و داخل `assets/images/` نگهداری می‌شوند؛ وابستگی به لینک بیرونی برای تصاویر رابط نداریم.
- نام فایل‌ها و پوشه‌ها انگلیسی، حروف کوچک و در صورت نیاز با خط تیره است.
- متن و محتوای هر صفحه داخل HTML آن قابل ویرایش است؛ ابزار build برای استفاده از سورس لازم نیست.
- قابلیت‌های نیازمند سرور باید در مستندات به عنوان نمونه مشخص باشند.

## نقشهٔ صفحه‌های پیشنهادی

| مسیر | کاربرد | وضعیت |
| --- | --- | --- |
| `pages/home/` | خانهٔ استور | نسخهٔ فارسی موبایل موجود |
| `pages/apps/` | فهرست اپلیکیشن‌ها | برنامه‌ریزی‌شده |
| `pages/games/` | فهرست بازی‌ها | برنامه‌ریزی‌شده |
| `pages/categories/` | دسته‌بندی‌ها | برنامه‌ریزی‌شده |
| `pages/search/` | جست‌وجو و نتایج | برنامه‌ریزی‌شده |
| `pages/app-detail/` | جزئیات اپ و نصب | برنامه‌ریزی‌شده |
| `pages/downloads/` | دانلودها و به‌روزرسانی‌ها | برنامه‌ریزی‌شده |
| `pages/profile/` | حساب کاربری | برنامه‌ریزی‌شده |

این مسیرهای برنامه‌ریزی‌شده هنوز صفحهٔ ساخته‌شده ندارند. فقط با شروع طراحی هر بخش ایجاد می‌شوند.

## ردیف‌های دسته‌بندی صفحهٔ اصلی

دسته‌های زیر هیرو، به ترتیب قرارگیری در HTML و `data-priority` نمایش داده می‌شوند. هر دسته یک `section.game-category` مستقل و یک `.game-rail` با اسکرول افقی RTL دارد. عرض کارت‌ها برای نمایش حدود یک کارت و نیم تنظیم شده است. افزودن دستهٔ جدید با تکرار همین ساختار انجام می‌شود.

دادهٔ فعلی کارت‌ها از پنج بازی ارسال‌شدهٔ صاحب پروژه است. آمیرزا بدون امتیاز است. جست‌وجو کارت‌های نامرتبط و دسته‌های بدون نتیجه را پنهان می‌کند و بازی‌های تکرارشده در چند دسته را در شمارش نتایج یک بار حساب می‌کند.

## کشف بازی‌ها و اسکرول بی‌نهایت

`assets/js/discovery.js` کارت‌های پنج بازی واقعیِ ارسال‌شده را برای نمونهٔ طراحی، در بسته‌های ۱۲تایی تکرار می‌کند. `IntersectionObserver` نزدیک انتهای فهرست، بستهٔ بعدی را با تأخیر نمایشی ۸۵۰ میلی‌ثانیه اضافه می‌کند. بارگذاری هم‌زمان تکراری مسدود است و دکمهٔ بارگذاری دستی هم وجود دارد. هنوز API یا صفحه‌بندی سرور به این بخش وصل نیست.
