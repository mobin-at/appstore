# Appstore — رابط استور اندرویدی

پروژهٔ HTML و CSS برای طراحی یک استور اپلیکیشن اندروید با تمرکز بر کاربران ایرانی. فایل‌ها مستقل از فریم‌ورک هستند تا بعداً در اپ یا WebView قابل استفاده باشند.

## اجرا

از ریشهٔ پروژه اجرا کنید:

```sh
python3 -m http.server 8000
```

سپس `http://localhost:8000` را باز کنید. برای مشاهدهٔ مستقیم نیز می‌توانید `pages/home/index.html` را باز کنید.

## ساختار

```text
index.html                 ورودی و انتقال به صفحهٔ اصلی
pages/
  home/index.html          صفحهٔ اصلی فعلی
assets/
  css/mobile.css           استایل مشترک و واکنش‌گرا
  js/main.js               تعامل‌های سبک رابط
  images/games/            تصاویر نمونهٔ بازی‌ها
docs/
  architecture.md          قرارداد پوشه‌ها و مسیر صفحه‌های آینده
.openai/hosting.json        تنظیمات پیش‌نمایش میزبانی‌شده
```

## وضعیت

صفحهٔ اصلی فعلی فارسی و راست‌به‌چپ است؛ با فونت محلی ایران‌سنس موبایل با اعداد فارسی، نام‌های فارسی و اصلی بازی‌ها، امتیازهای فارسی و نوار ناوبری پایین مناسب موبایل. چیدمان با مرجع TapTap ساخته شده است. محتوای فعلی همچنان بازی‌های نمونه است؛ بخش اپلیکیشن‌ها در مراحل بعد طراحی می‌شود.

منو، جست‌وجوی محلی و تغییر ظاهر برای نمونه کار می‌کنند. سرویس دانلود، ورود و رتبه‌بندی واقعی هنوز پیاده‌سازی نشده‌اند. تصاویر و نشان TapTap متعلق به صاحبانشان هستند و محتوای مرجع اولیه‌اند؛ پیش از انتشار محصول باید جایگزین شوند.

## پیش‌نمایش Sites

خروجی میزبانی در `dist/` ساخته می‌شود و در گیت نگهداری نمی‌شود. برای تولید آن:

```sh
python3 scripts/build-static.py
```

فونت فعلی ایران‌سنس موبایل (FaNum) با وزن‌های ۲۰۰، ۳۰۰، ۴۰۰، ۵۰۰ و ۷۰۰ است؛ فایل‌ها توسط صاحب پروژه ارائه شده‌اند و در `assets/fonts/` نگهداری می‌شوند. جست‌وجو از عنوان فارسی، انگلیسی و ژانر بازی‌ها پشتیبانی می‌کند.

خروجی مستقل HTML با `scripts/build-static.py` و خروجی مخصوص میزبانی Sites با `python3 scripts/build-hosted.py` ساخته می‌شود. بستهٔ میزبانی، HTML و استایل‌ها و تصاویر را از همان سورس قابل استفادهٔ مجدد سرو می‌کند.

لوگوی فعلی `assets/images/brand/cutting-edge.svg` بازسازی برداری از نمونهٔ تصویری است؛ با دریافت فایل اصلی می‌توان آن را جایگزین کرد.
